# Лабораторная работа: Система поддержки принятия решений на основе базы знаний / онтологии (Knowledge-based support system)

## Цель работы

Целью этой лабораторной работы является разработка программы (рекомендательной системы), которая будет использовать базу знаний или онтологию для предоставления рекомендаций на основе введенных пользователем данных.

## Задание

1. Создать программу, которая позволяет пользователю ввести запрос через командную строку. Например, информацию о себе, своих интересах и предпочтениях в контексте выбора видеоигры — на основе фактов из БЗ (из первой лабы) / Онтологии (из второй).

2. Использовать введенные пользователем данные, чтобы выполнить логические запросы к БЗ / Онтологии.

3. На основе полученных результатов выполнения запросов система должна предоставить рекомендации или советы, связанные с выбором из БЗ или онтологии.

4. Система должна выдавать рекомендации после небольшого диалога с пользователем.

## Пример

**Входная строка:** Я играю за rome, сейчас эра classical, ресурсы iron, стиль melee 

**Рекомендации:**

- Твой уникальный юнит: samurai
- В эту эру доступны юниты: warrior, archer, horseman, catapult, swordsman, crossbowman, trebuchet, scout
- Лучший юнит для твоего стиля игры: archer
- Чтобы строить archer, нужна технология: archery
- В следующей эре (renaissance) откроются: caravel
- Если добудешь horses, сможешь строить: knight
